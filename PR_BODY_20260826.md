## KYC

Gemini est entièrement retiré de cette branche. Le navigateur exécute localement les pré-contrôles disponibles : qualité minimale du document, OCR Tesseract.js et détection d’un visage par MediaPipe ; ONNX Runtime Web est installé comme base d’intégration future pour un modèle évalué. Ces résultats ne sont pas considérés comme une preuve serveur : si les contrôles sont incomplets, le dossier reste `pending` et part en revue humaine. Aucun liveness complet ni modèle de comparaison visage-document n’est prétendu terminé. Le selfie ne devient la photo de profil qu’après approbation complète.

## Storage et RLS

Les dossiers KYC restent dans un bucket privé. Les annonces publiques, médias publics et assets publics restent séparés. L’audit a identifié une politique `Public brand asset upload` avec rôle `anon` sur un nom d’asset déterminé ; la migration de retrait est préparée mais non exécutée. Les règles RLS KYC, conversations, annonces, favoris et administration n’ont pas été modifiées dans cette PR.
